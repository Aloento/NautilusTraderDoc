期权数据与 Greeks（Bybit）

备注

本教程仅用 Rust，通过 Rust LiveNode 配合 Bybit 适配器流式获取实时期权 Greeks 与聚合的期权链快照。

本教程连接 Bybit 的实时期权市场，通过两个 DataActor 示例消费 Greeks 与期权链 数据，覆盖金融工具发现、交易场所提供的 Greeks 订阅，以及带 ATM 相对行权价过滤的 周期性期权链快照。

简介​

Bybit 在每条期权行情更新中同时发布 Greeks（delta、gamma、vega、theta）与隐含 波动率。NautilusTrader 以两个层级暴露这些数据：

  • 逐工具 Greeks：订阅单个期权合约，每次行情更新收到一个 OptionGreeks 事件。
  • 期权链快照：订阅整个到期日序列，周期性收到 OptionChainSlice 事件，聚合序列内全部活跃行权价的报价与 Greeks。

两个示例二进制分别展示这两种模式：第一个订阅单个合约的 Greeks 数据流；第二个订阅 带 ATM 相对行权价过滤的聚合期权链。

前置条件​

  • 可用的 Rust 工具链（rustup.rs）。
  • 已克隆并能构建 NautilusTrader 仓库。

示例不需要 Bybit API key：api_key 与 api_secret 留空，数据客户端使用 Bybit 的公共行情端点，不从环境读取凭据。

注意

Bybit 的 demo 交易只在私有数据流上使用 stream-demo.bybit.com。 公共期权行情使用主网公共流 wss://stream.bybit.com/v5/public/option。

DataActor 模式​

Rust 的 DataActor 需要三部分：

  1. 一个含 core: DataActorCore 字段和自有状态的 struct。
  2. nautilus_actor!(YourType) 宏加一个 Debug 实现。
  3. 带回调的 DataActor trait 实现。

宏提供 blanket Actor 与 Component 实现所需的原生运行时连接，你只需实现 用到的回调。每个回调都有默认的 no-op 实现。

第一部分：逐工具 Greeks​

bybit-greeks-tester 示例为最近到期日的所有 BTC CALL 期权订阅 OptionGreeks， 并记录每条更新。

Actor 结构​

#[derive(Debug)]
struct GreeksTester {
    core: DataActorCore,
    client_id: ClientId,
    subscribed_instruments: Vec<InstrumentId>,
}

nautilus_actor!(GreeksTester);

impl GreeksTester {
    fn new(client_id: ClientId) -> Self {
        Self {
            core: DataActorCore::new(DataActorConfig {
                actor_id: Some("GREEKS_TESTER-001".into()),
                ..Default::default()
            }),
            client_id,
            subscribed_instruments: Vec::new(),
        }
    }
}

宏要求 core 字段。client_id 标识订阅所用的数据客户端。 subscribed_instruments 向量记录订阅列表，actor 停止时据此退订。

发现金融工具​

启动时，actor 从缓存查询所有期权金融工具，过滤出未到期的 BTC CALL，并找到最近 到期日：

fn on_start(&mut self) -> anyhow::Result<()> {
    let venue = Venue::new("BYBIT");
    let underlying_filter = Ustr::from("BTC");

    let mut options: Vec<(InstrumentId, f64, u64)> = {
        let cache = self.cache();
        let instruments = cache.instruments(&venue, Some(&underlying_filter));

        instruments
            .iter()
            .filter_map(|inst| {
                if inst.option_kind() == Some(OptionKind::Call) {
                    let expiry = inst.expiration_ns()?.as_u64();
                    let strike = inst.strike_price()?.as_f64();
                    Some((inst.id(), strike, expiry))
                } else {
                    None
                }
            })
            .collect()
    }; // cache borrow dropped here

    let now_ns = self.timestamp_ns().as_u64();
    options.retain(|(_, _, exp)| *exp > now_ns);

    let nearest_expiry = options.iter().map(|(_, _, exp)| *exp).min().unwrap();
    options.retain(|(_, _, exp)| *exp == nearest_expiry);
    options.sort_by(|(_, a, _), (_, b, _)| a.partial_cmp(b).unwrap());

    // ...subscribe to each
}
注意

调用任何订阅方法前先释放缓存借用。缓存内部使用 Rc<RefCell<...>>， 订阅方法可能需要借用它。把拥有的数据收集到本地 Vec，释放缓存引用， 然后再订阅。

订阅 Greeks​

发现金融工具后逐一订阅：

let client_id = self.client_id;
for (instrument_id, _, _) in &options {
    self.subscribe_option_greeks(*instrument_id, Some(client_id), None);
    self.subscribed_instruments.push(*instrument_id);
}

处理更新​

Bybit 的每条行情更新都会以 OptionGreeks 事件触发 on_option_greeks：

fn on_option_greeks(&mut self, greeks: &OptionGreeks) -> anyhow::Result<()> {
    log::info!(
        "GREEKS | {} | delta={:.4} gamma={:.6} vega={:.4} theta={:.4} rho={:.6} | \
         mark_iv={} bid_iv={} ask_iv={} | underlying={} oi={}",
        greeks.instrument_id,
        greeks.delta,
        greeks.gamma,
        greeks.vega,
        greeks.theta,
        greeks.rho,
        greeks.mark_iv.map_or("-".to_string(), |v| format!("{v:.2}")),
        greeks.bid_iv.map_or("-".to_string(), |v| format!("{v:.2}")),
        greeks.ask_iv.map_or("-".to_string(), |v| format!("{v:.2}")),
        greeks.underlying_price.map_or("-".to_string(), |v| format!("{v:.2}")),
        greeks.open_interest.map_or("-".to_string(), |v| format!("{v:.1}")),
    );
    Ok(())
}

OptionGreeks 的字段：

字段类型说明
instrument_idInstrumentId期权合约。
conventionGreeksConventionGreeks 约定（BlackScholes 或 PriceAdjusted）。
deltaf64价格对标的的敏感度。
gammaf64delta 对标的的敏感度。
vegaf64价格对波动率变化 1% 的敏感度。
thetaf64每日时间衰减。
rhof64对利率变化的敏感度。
mark_ivOption<f64>标记价格的隐含波动率。
bid_ivOption<f64>买价隐含波动率。
ask_ivOption<f64>卖价隐含波动率。
underlying_priceOption<f64>交易场所给出的该到期日参考价。
open_interestOption<f64>该合约的未平仓合约数。
ts_eventUnixNanos事件发生时刻的 UNIX 时间戳（纳秒）。
ts_initUnixNanos实例初始化时刻的 UNIX 时间戳（纳秒）。

delta、gamma、vega、theta、rho 存放在嵌套的 greeks: OptionGreekValues 结构体中。OptionGreeks 实现了 Deref<Target = OptionGreekValues>，因此可以像 上面那样通过 greeks.delta 等字段直接访问。

Bybit 不提供 rho，适配器把它置为 0.0。

清理​

停止时退订全部金融工具：

fn on_stop(&mut self) -> anyhow::Result<()> {
    let ids: Vec<InstrumentId> = self.subscribed_instruments.drain(..).collect();
    let client_id = self.client_id;
    for instrument_id in ids {
        self.unsubscribe_option_greeks(instrument_id, Some(client_id), None);
    }
    log::info!("Unsubscribed from all option greeks");
    Ok(())
}

第二部分：期权链快照​

bybit-option-chain 示例订阅聚合期权链，周期性记录快照，展示每个行权价的 call 与 put 及其报价和 Greeks。

为什么用期权链​

逐工具订阅便于控制单个合约，但要看整条曲面就得管理一条条独立数据流，还要跨行权价 关联更新。期权链订阅通过 DataEngine 完成这件事：聚合序列中所有行权价的报价与 Greeks，按定时器发布单个 OptionChainSlice。

这一聚合发生在 NautilusTrader 内部。Bybit 按合约发布期权行情，其 V5 公共 WebSocket 文档没有定义原生的期权链数据流。

期权链类型​

OptionSeriesId 标识单个到期日序列：

let series_id = OptionSeriesId::new_derived(
    Venue::new("BYBIT"),    // venue
    Ustr::from("BTC"),      // underlying
    Ustr::from("USDT"),     // settlement currency
    UnixNanos::from(expiry), // expiration timestamp
);

StrikeRange 控制哪些行权价处于激活状态：

变体说明
Fixed固定的行权价集合。
AtmRelativeATM 上方 strikes_above 个、下方 strikes_below 个行权价。
AtmPercentATM 价格 pct 范围内的全部行权价。
Deltacall 或 put 绝对 delta 与 target 之差在 tolerance 内的行权价。

动态行权价范围会等引擎从交易场所参考价确定 ATM 价格后才生效。

订阅​

let strike_range = StrikeRange::AtmRelative {
    strikes_above: 3,
    strikes_below: 3,
};

let snapshot_interval_ms = Some(5_000); // snapshot every 5 seconds

self.subscribe_option_chain(
    series_id,
    strike_range,
    snapshot_interval_ms,
    Some(client_id),
    None, // params
);

原始模式下 snapshot_interval_ms 传 None：每条报价或 Greeks 更新都立即发布 一个切片。

处理快照​

on_option_chain 回调收到 OptionChainSlice，包含全部活跃行权价及其 call 和 put 数据：

fn on_option_chain(&mut self, slice: &OptionChainSlice) -> anyhow::Result<()> {
    log::info!(
        "OPTION_CHAIN | {} | atm={} | calls={} puts={} | strikes={}",
        slice.series_id,
        slice.atm_strike.map_or("-".to_string(), |p| format!("{p}")),
        slice.call_count(),
        slice.put_count(),
        slice.strike_count(),
    );

    for strike in slice.strikes() {
        let call_info = slice.get_call(&strike).map(|d| {
            let greeks_str = d.greeks.as_ref().map_or("-".to_string(), |g| {
                format!(
                    "d={:.3} g={:.5} v={:.2} iv={:.1}%",
                    g.delta, g.gamma, g.vega,
                    g.mark_iv.unwrap_or(0.0) * 100.0,
                )
            });
            format!("bid={} ask={} [{}]", d.quote.bid_price, d.quote.ask_price, greeks_str)
        });

        let put_info = slice.get_put(&strike).map(|d| {
            let greeks_str = d.greeks.as_ref().map_or("-".to_string(), |g| {
                format!(
                    "d={:.3} g={:.5} v={:.2} iv={:.1}%",
                    g.delta, g.gamma, g.vega,
                    g.mark_iv.unwrap_or(0.0) * 100.0,
                )
            });
            format!("bid={} ask={} [{}]", d.quote.bid_price, d.quote.ask_price, greeks_str)
        });

        log::info!(
            "  K={} | CALL: {} | PUT: {}",
            strike,
            call_info.unwrap_or_else(|| "-".to_string()),
            put_info.unwrap_or_else(|| "-".to_string()),
        );
    }

    Ok(())
}

OptionChainSlice 的字段与方法：

名称类型 / 返回说明
series_idOptionSeriesId该快照覆盖的序列。
atm_strikeOption<Price>由参考价确定的 ATM 行权价。
call_count()usize有数据的 call 行权价数量。
put_count()usize有数据的 put 行权价数量。
strike_count()usize全部行权价的并集数量。
strikes()Vec<Price>全部行权价的有序列表。
get_call(k)Option<&OptionStrikeData>行权价 k 的 call 报价与 Greeks。
get_put(k)Option<&OptionStrikeData>行权价 k 的 put 报价与 Greeks。

每个 OptionStrikeData 含一个 quote: QuoteTick（买卖价）和可选的 greeks: Option<OptionGreeks>。

节点设置​

两个示例使用相同的 LiveNode 模式。只用数据时不需要执行客户端：

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    dotenvy::dotenv().ok();

    let environment = Environment::Live;
    let trader_id = TraderId::from("TESTER-001");
    let client_id = ClientId::new("BYBIT");

    let bybit_config = BybitDataClientConfig {
        api_key: None,    // public market data needs no credentials
        api_secret: None,
        product_types: vec![BybitProductType::Option],
        ..Default::default()
    };

    let client_factory = BybitDataClientFactory::new();

    let mut node = LiveNode::builder(trader_id, environment)?
        .with_name("BYBIT-OPTIONS-001".to_string())
        .add_data_client(None, Box::new(client_factory), Box::new(bybit_config))?
        .with_delay_post_stop_secs(5)
        .build()?;

    let actor = GreeksTester::new(client_id); // or OptionChainTester
    node.add_actor(actor)?;
    node.run().await?;

    Ok(())
}

product_types 设为 [BybitProductType::Option] 时，客户端只加载期权金融工具。 启动时会等金融工具提供器拉取并解析全部挂牌期权。

运行示例​

# Per-instrument Greeks
cargo run --example bybit-greeks-tester --package nautilus-bybit --features examples

# Option chain snapshots
cargo run --example bybit-option-chain --package nautilus-bybit --features examples

Ctrl+C 停止任一示例。actor 的 on_stop 回调会在关闭前退订全部数据流。

面板图​

图 1. 最近到期日每个 BTC CALL 行权价的最后 delta，标的约 77,000 USDT 已标记。 delta 从标的下方的约 0.45 跌到标的上方接近零。Bybit 在临近到期、gamma 近零的合约上 给出的 delta 在 ATM 附近压缩成阶梯状。
