教程

这些教程按步骤讲解 NautilusTrader 的功能与工作流。

信息

多数 Python 教程是 Jupytext percent 格式文件，位于文档仓库的 tutorials 目录。 这些文件既可以直接当脚本运行，也可以通过 Jupytext 作为 notebook 打开。 Rust 教程按其页面上给出的命令运行。

备注
  • Latest：基于 master 分支构建的文档，对应稳定版本。 见 https://nautilustrader.io/docs/latest/tutorials/。
  • Nightly：基于 develop 分支构建的文档，包含实验性功能。 见 https://nautilustrader.io/docs/nightly/tutorials/。

推荐顺序​

刚接触 NautilusTrader 的话，按以下顺序完成教程：

  1. Quickstart：用合成数据在五分钟内跑通第一个回测。
  2. 回测（低层 API）：直接使用 BacktestEngine， 配合真实行情数据与执行算法。
  3. 回测（高层 API）：用 BacktestNode 和 Parquet 数据目录 运行配置驱动的回测。
  4. 加载外部数据：把 CSV 或其他外部数据加载到 ParquetDataCatalog（操作指南）。
  5. 使用 FX K 线数据回测：对 FX K 线回测，并模拟隔夜利息。
  6. 再从下面的列表中挑选感兴趣的专题教程。
